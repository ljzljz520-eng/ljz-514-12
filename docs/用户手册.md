# 用户手册（中文）

## 1. 访问系统
- 打开浏览器访问：`http://localhost:3514/`

## 2. 主要功能

### 2.1 查看景点
- 地图上会显示所有景点标注（Marker）
- 点击标注可查看简介，并可直接设为起点或终点

### 2.2 选择起点/终点
- 左侧控制面板选择“起点”和“终点”
- 支持输入关键词搜索景点名称

### 2.3 选择寻路偏好
- “综合耗时”（默认）：同时考虑步行/乘车时间、坡度、拥挤、换乘等候，整体最省心
- “最短距离”：只看道路距离，可能会选出更陡、更挤或更耗体力的近路
- “最少换乘”：优先纯步行/直达，少等车但可能更慢

### 2.4 开始规划
- 点击“开始规划”
- 系统默认按综合耗时找路，在地图上按通行方式逐段着色画出路线（步行蓝、公交紫、轨道青）
- “路径结果”中可以看到：
  - **方案卡片**：推荐路线与其他走法的耗时、距离、换乘、爬升差异（“为什么这条路更合适”）
  - **综合耗时构成条**：基础耗时 / 坡度附加 / 拥挤延误 / 换乘等候各占多少
  - **逐段明细**：每段怎么走、多远、多久、坡度方向（上坡/下坡）、挤不挤、要不要换乘，
    以及该路段的真实路况备注
- 地图上灰色虚线表示其他走法，可直观对比走向差异

### 2.5 常用操作
- “交换”：交换起点与终点（注意：上坡会变成下坡，综合耗时可能变化）
- “清空”：清除起点/终点与规划结果

## 3. 常见问题

### 3.1 页面提示“加载节点失败”
- 检查后端是否启动：访问 `http://localhost:8514/api/health`
- 若未启动，建议执行：`docker compose up -d --build`

### 3.2 地图底图无法显示
- 底图来自 OpenStreetMap，离线或网络受限时可能无法加载
- 不影响路径规划与列表展示

## 4. 操作演练（合并）

### 4.1 一键启动
在项目根目录执行：
```bash
docker compose up -d --build
```

启动后访问：
- 前端：`http://localhost:3514/`
- 后端健康：`http://localhost:8514/api/health`

### 4.2 数据加载说明
- 启动后端时：
  - 若数据库无节点：从 `nodes.csv` 导入节点到 PostgreSQL
  - 读取 `edges.csv`：若存在则用其构图；否则按地理距离自动生成边

### 4.3 路径规划演练
1) 在左侧选择起点、终点（或在地图 Marker 弹窗中设置）
2) 点击“开始规划”
3) 在地图查看路线，在控制面板查看路径节点列表与每段距离

### 4.4 接口示例
```bash
curl -sS http://localhost:8514/api/nodes
curl -sS "http://localhost:8514/api/path?from=JIEFANGBEI&to=HONGYADONG"
```
