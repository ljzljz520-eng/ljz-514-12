# 用户手册（中文）

## 1. 访问系统
- 打开浏览器访问：`http://localhost:3514/`

## 2. 主要功能

### 2.1 查看景点
- 地图上会显示所有景点标注（Marker）
- 点击标注可查看简介，并可直接设为起点或终点

### 2.2 选择起点/终点
- 左侧控制面板选择“起点”和“终点”
- 支持输入关键词搜索景点名称

### 2.3 开始规划
- 点击“开始规划”
- 系统按“综合耗时”（步行耗时经坡度、拥挤修正并计入换乘惩罚）计算最合适的路线，并在地图上画出路线
  - 路线按拥挤程度着色：绿=清净、黄=一般、红=拥挤；虚线表示该段需换乘（右下角有图例）
- 下方“路径结果”显示：
  - 汇总指标：综合耗时、纯步行耗时、总距离、换乘次数、最大坡度、平均拥挤
  - 途经景点顺序，以及每两个景点之间的明细（步行耗时、距离、坡度、拥挤程度、是否需换乘）
  - “为什么推荐这条路？”：与备选路线的逐项对比，说明推荐路线省在哪里、备选路线的取舍是什么

### 2.4 常用操作
- “交换”：交换起点与终点
- “清空”：清除起点/终点与规划结果

## 3. 常见问题

### 3.1 页面提示“加载节点失败”
- 检查后端是否启动：访问 `http://localhost:8514/api/health`
- 若未启动，建议执行：`docker compose up -d --build`

### 3.2 地图底图无法显示
- 底图来自 OpenStreetMap，离线或网络受限时可能无法加载
- 不影响路径规划与列表展示

## 4. 操作演练（合并）

### 4.1 一键启动
在项目根目录执行：
```bash
docker compose up -d --build
```

启动后访问：
- 前端：`http://localhost:3514/`
- 后端健康：`http://localhost:8514/api/health`

### 4.2 数据加载说明
- 启动后端时：
  - 若数据库无节点：从 `nodes.csv` 导入节点到 PostgreSQL
  - 读取 `edges.csv`：若存在则用其构图；否则按地理距离自动生成边

### 4.3 路径规划演练
1) 在左侧选择起点、终点（或在地图 Marker 弹窗中设置）
2) 点击“开始规划”
3) 在地图查看路线（颜色表示拥挤程度、虚线表示需换乘），在控制面板查看汇总指标、每段明细与备选路线对比

### 4.4 接口示例
```bash
curl -sS http://localhost:8514/api/nodes
curl -sS "http://localhost:8514/api/path?from=JIEFANGBEI&to=HONGYADONG"
```
